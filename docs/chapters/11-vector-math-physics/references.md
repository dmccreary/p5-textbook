# References: Vector Math Fundamentals & Physics Acceleration

1. [Euclidean vector](https://en.wikipedia.org/wiki/Euclidean_vector) - Wikipedia - Geometric and algebraic treatment of vectors with magnitude and direction, vector addition, scalar multiplication, dot products, and normalization. Foundational for game physics and motion.

2. [Newton's laws of motion](https://en.wikipedia.org/wiki/Newton%27s_laws_of_motion) - Wikipedia - Classical mechanical laws governing inertia, force accumulation (F = ma), and action-reaction pairs. Provides the physical foundation for realistic acceleration models in simulation software.

3. [Euler method](https://en.wikipedia.org/wiki/Euler_method) - Wikipedia - Numerical integration method for solving ordinary differential equations by stepping velocity and position over discrete time intervals in real-time graphical simulation loops.

4. The Nature of Code: Simulating Natural Systems with Processing (Second Edition) - Daniel Shiffman - Self-Published / No Starch Press - Shiffman created the canonical creative coding physics architecture, establishing the Location-Velocity-Acceleration update loop that empowers students to simulate Newtonian mechanics with intuitive vector code.

5. Physics for Animators - Michele Bousquet - Focal Press / Routledge - Bousquet pioneered visual, artist-focused explanations of gravity, terminal velocity, friction coefficients, and bounce elasticity without overwhelming mathematical jargon for animators and designers.

6. [p5.Vector Class Reference](https://p5js.org/reference/#/p5.Vector) - p5.js Foundation - Complete API documentation covering p5.Vector static and instance methods: add, sub, mult, div, mag, heading, normalize, limit, and dist for vector arithmetic.

7. [The Nature of Code: Vectors Chapter](https://natureofcode.com/vectors/) - The Nature of Code - Interactive textbook chapter explaining vector arithmetic, motion with acceleration towards mouse cursor, and magnitude scaling with live p5.js sketches and interactive simulations.

8. [The Nature of Code: Forces Chapter](https://natureofcode.com/forces/) - The Nature of Code - In-depth guide implementing Newton's second law, mass scaling, wind forces, fluid drag resistance, and gravitational attraction in p5.js physics systems and simulations.

9. [Khan Academy: Vectors and 2D Motion Physics](https://www.khanacademy.org/science/physics/two-dimensional-motion) - Khan Academy - Introductory physics module covering vector components, displacement vectors, velocity vectors, and projectile trajectories with interactive quizzes and visual diagrams for science students.

10. [Integration Basics in Game Physics](https://gafferongames.com/post/integration_basics/) - Gaffer on Games (Glenn Fiedler) - Seminal technical article comparing Explicit Euler, Semi-Implicit Euler, and Verlet numerical integration techniques for robust, stable physics simulations in interactive web games.
