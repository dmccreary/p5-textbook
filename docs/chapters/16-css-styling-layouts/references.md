# References: CSS Styling, Layouts & Web Page Integration

1. [CSS](https://en.wikipedia.org/wiki/CSS) - Wikipedia - Exhaustive history and specification of Cascading Style Sheets, box models, cascading inheritance, and selector specificity governing visual layout on the web.

2. [Responsive web design](https://en.wikipedia.org/wiki/Responsive_web_design) - Wikipedia - Design philosophy using fluid grids, flexible media, and CSS media queries to adapt web layouts seamlessly across desktop, tablet, and mobile displays.

3. [CSS box model](https://en.wikipedia.org/wiki/CSS_box_model) - Wikipedia - Structural model defining content boundaries, padding, borders, and margins. Essential for aligning canvas elements with surrounding HTML interface components and text.

4. CSS: The Definitive Guide (Fifth Edition) - Eric A. Meyer and Estelle Weyl - O'Reilly Media - Meyer and Weyl formulated the definitive explanations of CSS visual formatting models, margin collapsing, and stacking contexts that govern browser element positioning and layout geometry.

5. Responsive Web Design (Second Edition) - Ethan Marcotte - A Book Apart - Marcotte coined Responsive Web Design and established the fluid grid proportion formulas that allow digital artwork and canvas frames to scale gracefully on any screen size.

6. [CSS Flexible Box Layout (Flexbox) Guide](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_flexible_box_layout/Basic_concepts_of_flexbox) - MDN Web Docs - Comprehensive guide to 1D flex layouts, justify-content, align-items, flex-direction, and centered canvas wrappers for modern web layout styling and responsive design structures.

7. [CSS Grid Layout Guide](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_grid_layout/Basic_concepts_of_grid_layout) - MDN Web Docs - Authoritative reference on 2D grid template areas, fractional units (fr), and responsive auto-fitting layouts for multi-sketch dashboards and creative portfolios.

8. [A Complete Guide to Flexbox](https://css-tricks.com/snippets/css/a-guide-to-flexbox/) - CSS-Tricks - Visual reference card illustrating all parent container and child item flexbox properties with intuitive visual diagrams for responsive web design and canvas container layouts.

9. [Styling p5.js Canvases and UI with CSS](https://p5js.org/reference/#/p5.Element/style) - p5.js Foundation - Documentation covering p5.Element style() and class() methods to dynamically apply CSS classes and inline styles to canvases and UI widgets.

10. [Embedding Canvases in iframes and Responsive Containers](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe) - MDN Web Docs - Comprehensive guide to embedding interactive sketches securely using iframe elements, managing sandbox permissions, aspect ratios, and cross-window messaging safely across web applications.
